## Capture rules

- Never capture credentials, tokens, database passwords, billing identifiers that are not already public project metadata, private customer data, or hidden chain-of-thought.
- Use synthetic Acme data only.
- Record exact command, commit, project, region, model, session/case IDs, and timestamp for external proof.
- A health endpoint proves availability only; it does not prove model execution, orchestration, mutation, or verification.
- A historical result stays labeled historical until rerun on the submitted commit.
